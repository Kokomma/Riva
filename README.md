# Riva
Riva is a wedding planning and vendor management platform built for Nigerian weddings, helping couples manage events, vendors, guests, and gifts in one place.

## MVP focus
- Role-based authentication (Couple, Vendor, Guest, Admin).
- Wedding creation with multi-event timelines and public RSVP pages.
- Vendor marketplace with categories, booking requests, and status tracking.
- In-app messaging between couples and vendors.
- Cash gift registry with Paystack integration.
- Admin dashboard for vendor approvals and oversight.

## Tech stack
- Next.js + React (frontend)
- Supabase + PostgreSQL (backend)
- Paystack (payments)

## Getting started
```bash
npm install
npm run dev
```
